# medium-article-writer
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.9+-blue.svg)]
[![Status](https://img.shields.io/badge/status-active-green.svg)]

A Python-based AI article generator using Google's Gemini API.

🧰 Features
✅ Generate 5 beginner-friendly topics per domain
✅ Write full 1000-word articles in Markdown
✅ Prevent topic repetition with history tracking
✅ Remove AI-sounding phrases and clichés
✅ GUI interface for easy use (Tkinter-based)
✅ Clean folder structure by date
✅ Optional: Cleanup old files automatically

📦 Requirements
Python 3.9+
Google AI Studio API key (free tier available)
Optional: Serper.dev API key (for trending topics)
Libraries: google-generativeai, tkinter, natsort
OS: Windows, macOS, or Linux

Install dependencies:
pip install google-generativeai natsort


✅ Why This Is Useful
Automate blog post creation
Build a content backlog
Learn how to work with LLMs and prompt engineering
Explore automation via GUI or CLI
Practice working with APIs, file systems, and scripting
